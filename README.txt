The report is now built into both the homepage and Flight Reports page as a four-section viewer:
1. Mission summary
2. Mission description
3. Preflight review
4. Linked quote

Only one section appears at a time. Readers can choose a tab or use Previous/Next. On mobile, the tabs form two rows so all four sections are easy to find. Each section opens its own full-size, single-page watermarked PDF. The complete four-page PDF remains an optional link.

All PDF pages and excerpt images come from the actual app-generated report. A light DEMO watermark identifies the sample. The uploaded original is unchanged. The website uses navy and green branding.
